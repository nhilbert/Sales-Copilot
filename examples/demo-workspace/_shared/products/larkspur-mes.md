# Larkspur MES (fictional example product)

## What it is
Manufacturing execution software for discrete manufacturers: order dispatch to work centres, electronic work instructions, machine data collection, production reporting. Deployed per plant from a shared template.

## Capabilities
- Plant template (one configuration rolled out to several plants) — generally available — factsheet 2026-08
- Electronic work instructions with versioning — generally available — factsheet 2026-08
- Machine data collection (OPC UA) — generally available — factsheet 2026-08
- ERP connector for production orders and confirmations (standard package) — announced for Q1 2027 — roadmap deck 2026-07
- Custom ERP integration via services — generally available — factsheet 2026-08

## Typical buyers and problems
COO and plant managers (throughput, transparency across plants), IT (integration, standardisation), quality (traceability).

## Not offered / limits
No scheduling optimisation; no maintenance management; the standard ERP connector is not yet available.

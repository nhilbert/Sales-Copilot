# One production template across all plants

## Challenge
Plants run the same products with different processes and systems, so performance cannot be compared and every improvement is made several times.

## Offer
Larkspur MES rolled out from one plant template: pilot in one plant, then template rollout plant by plant, with local deviations documented.

## Value
(plants − 1) × configuration effort avoided per plant + faster comparison of plant KPIs. Numbers only from the client's own rollout plans.

## Proof
Pilot at one plant; reference figures to be added when the pilot report is signed off.

## Fit conditions
Plants make comparable products; management wants comparability; IT accepts one more system next to the ERP.

## Gaps and risks
The standard ERP connector is announced, not available (see product file); until then integration is a services item.
